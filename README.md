# astrbot_plugin_pokeplus（戳一戳全能响应）




## 功能一览

- **戳一戳监测**：总开关，关闭后不再监听任何戳一戳事件。
- **表情包回复**：开关 + 概率（0~1），从图库目录随机抽一张图片发送。
- **回戳**：开关 + 概率（0~1），可配置最大回戳次数（实际 1~该值 随机）。
- **LLM 响应**：开关 + 回复设定（提示词模板，支持 `$username` / `$user_id` / `$scene` 变量），走 AstrBot 标准 LLM 链路，自动使用当前人格并记入对话上下文。
- **AI 自主戳一戳**：正常聊天时，AI 可根据语境自主决定是否在回复后戳一戳对方；带开关、考虑概率和冷却。
- **群聊 / 私聊独立配置**：以上所有功能在群聊和私聊中各有独立的一套配置。

## 回复优先级（核心规则）

当表情包、回戳、LLM 全部开启且概率相同时：

```
表情包 = 回戳  ≻  LLM 响应
```

- 表情包与回戳为**独立概率判定**，互不影响（只想触发其中一个，就把另一个的开关关掉或概率设为 0）。
- 命中的动作会**先**依次发出（表情包 → 回戳），**之后**才进行 LLM 响应。
  实现上：表情包/回戳在事件处理中同步发送，LLM 通过 `yield event.request_llm()` 异步生成，
  因此无论 LLM 速度多快，文字回复都一定晚于表情包和回戳到达。
- 回戳自带**响应延迟**（`poke_back_delay`，0~5 秒可调，默认 1 秒）：被戳后先等待一段时间再回戳，
  避免秒回显得像机器人；设为 0 则立即回戳。

## AI 自主戳一戳的工作原理

1. 正常聊天触发 LLM 时，插件在 `on_llm_request` 钩子往 system_prompt 追加一条
   「你拥有戳一戳能力，想让戳就在回复末尾输出 `[戳一戳]` 标记」的指令。
2. AI 根据语境自主决定是否使用。
3. 插件在 `on_llm_response` 钩子检测到标记后：**剥离标记**（用户看不到暗号），
   延迟约 1.5 秒（可配置）后执行戳一戳，保证戳的动作出现在文字回复**之后**。
4. 若 AI 只输出了标记没有正文，会以「（戳了戳你）」兜底发送。

## 安装

将本文件夹放入 AstrBot 的 `data/plugins/` 目录下（或在 WebUI 插件市场从仓库安装），
重载插件即可。无需额外 pip 依赖。

## 使用说明

1. **表情包图库**：插件内置三张默认表情包（`stickers_default/` 目录：歪脑、歪头、疑惑），
   开箱即用；想扩充就把图片放进配置的 `sticker_paths` 目录（默认
   `data/plugin_data/astrbot_plugin_pokeplus/stickers_group` 与 `.../stickers_private`，
   插件加载时会自动创建），支持子目录递归扫描，格式支持 jpg / png / gif / webp 等。
   内置默认表情包可通过各场景的 `use_default_stickers` 开关单独关闭。
2. **概率范围**：0~1 的小数，如 0.6 表示 60% 概率触发；设为 1 必定触发，0 必不触发。
3. **冷却**：`user_cooldown`（同一用户连戳）与 `session_cooldown`（同一会话被戳）双层防刷屏；
   AI 自主戳一戳另有独立的会话级冷却。
4. **AI 自主戳一戳**：默认开启（群聊冷却 180 秒、私聊 300 秒）。它只在 AI 正常聊天回复时生效，
   被戳触发的 LLM 回复不会再叠加此逻辑。

## 注意事项

- 戳一戳动作基于 OneBot v11 扩展 API（`group_poke` / `friend_poke`），请使用 **NapCat、
  Lagrange、LLOneBot** 等协议端；其他平台（Telegram 等）会自动跳过戳一戳动作，不影响其余功能。
- 被戳后的 LLM 回复依赖已配置好 LLM 提供商与人格。
- 建议停用其他戳一戳插件（如原版 pokepro / poke_to_llm），避免同一事件被多个插件重复响应。
- 若开启了 LLM **流式输出**，AI 自主戳一戳的暗号标记可能在打字机效果中短暂可见，建议使用默认的非流式（分段）输出模式。

## 配置项速查

| 配置 | 说明 | 默认 |
| --- | --- | --- |
| `poke_monitor` | 戳一戳监测总开关 | 开 |
| `user_cooldown` / `session_cooldown` | 被戳响应冷却（用户级/会话级，秒） | 5 / 5 |
| `reply_interval` | 表情包→回戳→LLM 之间的发送间隔（秒） | 0.8 |
| `private.*` / `group.*` | 私聊 / 群聊独立配置（私聊设置排在前面） | 见下 |
| `private.enable` / `group.enable` | **私聊/群聊功能一键开关**（关闭即停用该场景全部功能） | 开 |
| `sticker_enable` / `sticker_probability` | 表情包开关 / 概率 | 开 / 群0.6 私0.5 |
| `use_default_stickers` | 是否启用内置默认表情包（歪脑/歪头/疑惑） | 开 |
| `sticker_paths` | 表情包图库路径列表 | 自动创建的默认目录 |
| `poke_back_enable` / `poke_back_probability` / `poke_back_delay` / `poke_back_times` | 回戳开关 / 概率 / 响应延迟（0~5秒，防秒回） / 最大次数 | 开 / 群0.8 私0.7 / 1 / 1 |
| `llm_enable` / `llm_prompt` | LLM 响应开关 / 提示词模板 | 开 / 见配置 |
| `ai_poke_enable` / `ai_poke_probability` / `ai_poke_cooldown` | AI 自主戳开关 / 考虑概率 / 冷却（秒） | 开 / 1 / 群180 私300 |
| `ai_poke_marker` | AI 戳一戳暗号标记 | `[戳一戳]` |
| `ai_poke_delay` | AI 戳一戳延迟（秒） | 1.5 |
